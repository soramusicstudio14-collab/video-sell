# Subscriber Gift Video Generator (Bulk)

अपने सब्सक्राइबर्स को गिफ्ट के तौर पर भेजने के लिए पर्सनलाइज़्ड
"सब्सक्राइबर माइलस्टोन" वीडियो बनाता है — उनके चैनल के नाम/handle से
प्रोफाइल फोटो अपने-आप निकालकर, प्रीमियम बैकग्राउंड + कंफेटी/फायरवर्क के
साथ। एक चैनल के लिए भी चला सकते हैं, या CSV लिस्ट से एक साथ अनगिनत
(bulk) वीडियो भी बना सकते हैं।

## Setup (सिर्फ पहली बार)
```bash
pip install yt-dlp pillow numpy requests
```
ffmpeg इंस्टॉल होना चाहिए और PATH में उपलब्ध हो
(Windows: ffmpeg.org से डाउनलोड करके PATH में जोड़ें)।

`assets/` फोल्डर (फॉन्ट्स) स्क्रिप्ट के साथ उसी फोल्डर में रखें।

## इस्तेमाल

### एक चैनल के लिए
```bash
python subscriber_gift_video.py --channel "@channelhandle" --target 2000 --message "Thanks for subscribing!"
```
`--channel` में @handle, पूरा YouTube URL, या सिर्फ चैनल का नाम — तीनों चलेंगे।
सिर्फ नाम देने पर स्क्रिप्ट खुद सर्च करके सही चैनल ढूंढने की कोशिश करती है;
handle/URL देना हमेशा ज़्यादा भरोसेमंद रहेगा।

### बल्क (एक साथ कई चैनल/subscribers के लिए)
`sample_list.csv` जैसी फाइल बनाएं:
```csv
channel,target,message
@rahulgaming,2000,Thanks for being part of the journey!
Priya Vlogs,5000,Aap jaise subscribers ki wajah se ye mumkin hai!
```
फिर:
```bash
python subscriber_gift_video.py --batch sample_list.csv
```
इससे लिस्ट में जितने चैनल हैं, उतने वीडियो एक के बाद एक अपने-आप बन जाएंगे —
जितने चाहें उतने रो जोड़ सकते हैं (अनलिमिटेड)।

## आउटपुट लोकेशन और फाइलनेम
डिफ़ॉल्ट फोल्डर (स्क्रिप्ट के अंदर `DEFAULT_OUTDIR` में सेट है):
```
D:\ALL AUTOMATION FILE\youtube rendr
```
चाहें तो `--outdir "D:\कोई और फोल्डर"` से बदल सकते हैं।

डिफ़ॉल्ट फाइलनेम पैटर्न:
```
<ChannelName> - <count> SUBSCRIBER - GIFT VIDEO.mp4
```
बदलने के लिए:
```bash
--name-pattern "{name} - {count} SUBSCRIBER - GIFT VIDEO"
```
(`{name}` और `{count}` जगह पर असली वैल्यू आ जाएगी)

## माइलस्टोन (--target)
सिर्फ ये वैल्यू चलेंगी: **1000, 2000, 3000, 4000, 5000, 10000**
- 1000 से 5000 तक: हर 1000 पर कंफेटी + फायरवर्क-रे बर्स्ट
- 10000: 5000 तक वैसे ही पड़ाव, फिर बीच में रुके बिना सीधा 10000 पर बड़ा बर्स्ट

## नोट
- YouTube कभी-कभी बिना लॉगिन/कुकीज़ के चैनल पेज ब्लॉक कर देता है — फेल होने पर
  `--name` और `--avatar` (फोटो लोकल पाथ/लिंक) मैन्युअली दें, या CSV में
  `manual` कॉलम जोड़कर स्क्रिप्ट में `process_one()` कॉल को उसी हिसाब से बदल दें।
- रंग/फॉन्ट/टाइमिंग/साइज़ बदलने हैं तो स्क्रिप्ट के ऊपर `COLORS`, `W, H`,
  `AVATAR_SIZE`, और `render_video()` के `secs =` वाली लाइनें बदलें।
- यह टूल आपके अपने सब्सक्राइबर्स के लिए पर्सनलाइज़्ड गिफ्ट कंटेंट बनाने के
  लिए है — बनने वाला नंबर असली सब्सक्राइबर काउंट नहीं, बल्कि आपके दिए टारगेट
  तक की एनिमेशन है, यह ध्यान रखें कि इसे भ्रामक तरीके से इस्तेमाल न करें।
